## 质量维度
| 维度 | 标准 |
|---|---|
| 完整性 | 指标必需字段不得为空 |
| 唯一性 | 主键唯一，同一业务事实不得重复计数 |
| 有效性 | 状态、时间、类型符合字典约束 |
| 一致性 | 对象状态与关联事件、报名和参赛记录一致 |
| 及时性 | 日常运营数据原则上 T+1 前可用 |
| 可追溯性 | 数据可追溯到来源、操作人和修正记录 |

## 强制规则
- 已确认参赛必须关联有效玩家和已完成赛事。
- 已完成赛事必须有完成时间和授权确认人。
- 报名、战队、门店和赛事不得跨越未授权组织范围关联。
- 测试、作废和重复记录不得进入正式指标。
- 人工修正不得覆盖原值，必须保留原因、修改人和时间。

## 异常等级
P0：隐私泄露、跨组织越权或大范围错误决策风险；立即停止发布。

P1：核心指标明显错误或关键数据大量缺失；当日处理。

P2：局部缺失、延迟或非核心字段错误；进入修复队列。

## 处理流程
发现 → 隔离 → 定级 → 指派 Owner → 修复或重算 → 复核 → 发布说明 → 必要时复盘。质量未通过的数据必须显示状态，不能静默发布。
