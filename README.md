## L0 Core
OKOS V1.0 当前从 L0 Core 开始建设。L0 Core 是企业宪章层，负责定义 OK赛事联盟的使命、愿景、核心原则、治理边界和长期建设顺序。

OKOS 的建设顺序必须遵循：

1. L0 Core：企业宪章。
2. L1 Knowledge：企业知识。
3. L2 Playbooks：执行剧本。
4. L3 Product：产品。
5. L4 AI：AI员工。
6. L5 Data：数据。

每完成一层后暂停确认，未经确认不得进入下一层。
