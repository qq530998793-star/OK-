## 分类原则
赛事类型用于帮助 OK赛事联盟统一规划、沟通、执行和复盘赛事。赛事类型不是具体执行方案，具体执行方案在 L2 Playbooks 中定义。

## 基础赛事类型
L1 阶段定义以下基础赛事类型：

| 类型 | 定义 |
|---|---|
| Store Event | 以单一合作门店为主要场景的小型赛事 |
| City Event | 以城市为单位组织的多门店或区域赛事 |
| League Event | 有持续赛程、积分或阶段晋级机制的联赛型赛事 |
| Invitational Event | 邀请特定战队、玩家或合作对象参与的赛事 |
| Community Event | 以社群活跃、玩家互动或内容传播为主要目标的轻量赛事 |
| Partner Event | 与品牌、赞助商或合作伙伴共同发起的赛事 |

## 分类边界
同一赛事可以有主类型和辅助标签，但 Source of Truth 中必须只保留一个主类型，避免统计和复盘混乱。

正式赛事数据口径在 L5 Data 定义。
